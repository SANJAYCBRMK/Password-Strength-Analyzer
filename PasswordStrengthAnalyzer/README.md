# Password Strength Analyzer

## Objective
To analyze password strength based on length and complexity.

## Features
- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Suggests stronger passwords
- Prevents password reuse using SQLite database
- Uses SHA-256 hashing

## Technologies Used
- Python
- SQLite
- Hashlib
- Regular Expressions

## How to Run
python main.py
